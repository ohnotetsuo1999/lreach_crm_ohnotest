# ドキュメント一覧

## データベース設計ドキュメント

LINE配信自動化システムのデータベース構成に関する包括的なドキュメントです。

### 📚 ドキュメント構成

1. **[データベース構成ドキュメント](./database-schema.md)**
   - データベース全体の詳細な構成説明
   - 全テーブルの定義とカラム説明
   - リレーションシップの詳細
   - インデックス戦略
   - セキュリティ考慮事項

2. **[データベースER図](./database-er-diagram.md)**
   - Entity Relationship Diagram (Mermaid形式)
   - 主要なリレーションシップの視覚的表現
   - データフローの例
   - パフォーマンス最適化のポイント

3. **[データフローとシステムアーキテクチャ](./database-data-flow.md)**
   - システム全体のアーキテクチャ図
   - 主要なデータフローの説明
   - キャッシュ戦略
   - バックグラウンドジョブ
   - スケーラビリティ対策
   - 災害復旧計画

4. **[クイックリファレンス](./database-quick-reference.md)**
   - 主要テーブルの一覧
   - よく使うクエリパターン
   - 開発用コマンド集
   - 命名規則
   - トラブルシューティング

## 🎯 用途別ガイド

### 新機能開発時
1. [データベース構成ドキュメント](./database-schema.md) で既存のテーブル構造を確認
2. [データベースER図](./database-er-diagram.md) でリレーションシップを理解
3. [クイックリファレンス](./database-quick-reference.md) で命名規則を確認

### パフォーマンスチューニング
1. [クイックリファレンス](./database-quick-reference.md) の推奨インデックスを確認
2. [データフローとシステムアーキテクチャ](./database-data-flow.md) のキャッシュ戦略を参照
3. [データベースER図](./database-er-diagram.md) のパフォーマンス最適化セクションを確認

### トラブルシューティング
1. [クイックリファレンス](./database-quick-reference.md) でよくあるクエリパターンを確認
2. [データフローとシステムアーキテクチャ](./database-data-flow.md) でシステムの動作を理解
3. [データベース構成ドキュメント](./database-schema.md) でデータ整合性を確認

## 🔧 メンテナンス

### ドキュメント更新時の注意事項
